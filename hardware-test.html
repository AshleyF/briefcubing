GAN Gen4 hardware verification

Manual hardware acceptance tests for Brief Drills. This page runs entirely in your browser using the same gan-v4.js implementation as the proposed fix. It does not upload cube data or require an account.

1. Connection

Use Chrome on macOS, Linux, or Android. Close csTimer/Cubeast before testing. Turn the cube to wake it. Bluetooth requires HTTPS (or localhost).

On first connection you may be prompted for your cube's Bluetooth MAC. This is used locally to decrypt messages and stored only in this browser. Do not include the MAC in a shared test report.

2. Guided move verification

Do each step by physically turning the cube exactly once as shown. Use the clockwise direction relative to the face you're looking at. The checker rejects extra, missing, or wrong moves; it does not infer correctness from connection alone.

3. Robustness checks

These checks require manual observation. Mark PASS only after testing them; leave anything untested as NOT RUN.

4. Share results

Export a JSON report containing only test outcomes, counted turns, browser information, and sanitized diagnostics. No cube MAC, Bluetooth device ID, or unencrypted raw packets are exported. Upload the file to the PR or paste its contents in the discussion.
